# מנוע מצגות לימודיות — קול תודה

- `deck.py` — המנוע (CSS+JS+פונקציות שקופיות: `opening, gate, content, quiz, flow, node, src, expl, qbox, table, summary, takeaways, build`).
- `lib.py` — עטיפות קצרות + `save()` (מחליפות נתיב ל-`001 בראשית`; לשנות `BASE` לפרשה אחרת).
- `decks/` — תוכן 13 המצגות של פרשת בראשית; `build_ishah_asher_nasata.py` — המצגת הראשונה.
- `test_decks.js` — בדיקת Playwright (דסקטופ + מובייל, גלישה, שגיאות קונסול, חידונים). הרצה: `NODE_PATH=$(npm root -g) node test_decks.js [חלק משם הקובץ]`.
- הפרומפט המלא לבקשת מצגת: `../שונות/פרומפט - מצגת לימודית בסגנון קול תודה.md`.
