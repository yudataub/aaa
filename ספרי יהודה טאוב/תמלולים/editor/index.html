יצוא קוד HTML לקובץ מוכן

הדבק כאן קוד HTML, תן שם לקובץ, ולחץ "הורד קובץ HTML"

📂 גררו לכאן קובץ HTML, או

קובץ שנפתח כך מתחבר לדיסק — לחיצה על "💾 שמור" (או Ctrl+S) תעדכן את הקובץ המקורי עצמו, בלי ליצור עותק חדש.

תצוגה מקדימה

אפשר לסמן טקסט בתצוגה ולהדגיש (B) או להוסיף קו תחתון (U), וכן לתקן ישירות שגיאות כתיב — הכל ישתקף אוטומטית בקוד למעלה. לפתיחת קישור בזמן עריכה: Ctrl + לחיצה.

הוספת תמונה

קישור לגוגל דרייב יזוהה אוטומטית ויוטמע באמצעות iframe (השיטה הרשמית של גוגל) — הטמעה כתמונה רגילה מדרייב חסומה כיום.

התמונה חייבת להיות בפועל באותה תיקייה יחסית ליד קובץ ה-HTML כשמעלים את שניהם יחד.

מומלץ לתמונות קטנות בלבד — מגדיל את גודל קובץ ה-HTML.

הוספת קישור

הוספת בלון הסבר (Tooltip)

הטקסט הזה יופיע כבלון קטן כשעוברים עם העכבר מעל הטקסט שסימנתם.

הוספת פתק

הטקסט שסימנתם יהפוך לכותרת שאפשר ללחוץ עליה, והפתק ייפתח מתחתיה. בהדפסה ל-PDF הפתק נפתח אוטומטית כדי שהתוכן לא ייעלם.
